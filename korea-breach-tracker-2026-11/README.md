# 2026년 11월 국내 개인정보 유출 사고 정리 — 공통 접점과 점검 체크리스트

[한국어](README.md) | [English](README_en.md)

2026년 9월 말부터 11월까지 국내 금융·공공·유통·대학에서 확인된 유출 사고를 한 문서에 모았습니다. 개별 사건의 규모보다 중요한 것은 **어디서 뚫렸는가**입니다. 핵심 계정계가 아니라 외부 위탁, VOC 첨부파일, 레거시 연동, 가맹점·정산 접점이 반복해서 뚫렸습니다.

> 이 문서는 보도·기관 발표 기준 정리이며, 수사·조사에 따라 내용이 바뀔 수 있습니다. 확인 기준일 2026-11-26.

## 1. 금융권 — 37개사 40건, 47만 3천 건

- **2026-09-30 ~ 11-03**, 37개 금융사에서 40건의 침해사고 신고. 이름·주민번호·계좌번호 등 **47만 3천 건** 유출.
- 금융위원회는 580개 금융사를 대상으로 전수 점검에 착수했고, 신한은행은 2027년 보안 예산을 1,150억 원(올해 대비 약 2.8배)으로 늘렸습니다. 하나·우리·KB국민은행도 각 1,000억 원 이상 배정 + SIEM/SOAR 도입을 발표했습니다.
- 공격 표면: 핵심 계정계(직접 침해 아님, 망분리·내부통제 유지) / **영업지원·대출모집인 조회 API 권한 검증 누락** / 직원 모바일·그룹웨어 인증·세션 관리 / **외주·제3자 연계 서버**.

## 4. 사내 점검 체크리스트

### 4-1. 조회 API — BOLA/IDOR

- [ ] 모든 조회 API에서 **세션 사용자 == 리소스 소유자** 검증 (ID를 받아 그대로 조회하지 않기)
- [ ] 리소스 ID는 순차 번호 대신 UUID v4 등 추측 불가 값
- [ ] 목록·검색 API에도 동일한 소유자 스코프 적용 (필터 우회 확인)
- [ ] 대량 조회에 **사용자·토큰 단위 카디널리티 제한** (IP 단위만으로는 부족)
- [ ] 비정상 대량 SELECT를 WAF·DAM에서 탐지·차단

### 4-2. 첨부파일 (VOC·게시판·상담)

- [ ] 다운로드 API마다 작성자·권한 검증
- [ ] S3·NAS 버킷 퍼블릭 차단, **짧은 만료 Presigned URL**로만 제공
- [ ] 신분증·통장 사본 등 비구조화 첨부의 자동 마스킹·보관 기간 후 파기
- [ ] 첨부 URL 추측·재사용 테스트를 배포 전 검사에 포함

### 4-3. 레거시·외부 접점

- [ ] 폐기된 구형 시스템·옛 홈페이지·하위 도메인 인벤토리와 외부 노출 차단
- [ ] 외주·수탁사 API 키 분리 발급 + IP 제한 + 사용량 모니터링
- [ ] 그룹웨어·모바일웹 MFA, 세션 만료, 비정상 위치 로그인 차단
- [ ] 망분리 예외(업무망↔인터넷) 목록 최소화·정기 재승인

### 4-4. 결제·정산 (KICC 사고 대응)

- [ ] **11/20 이후** 가맹점 정산계좌 변경 이력과 실제 입금 계좌 전수 대조
- [ ] 제휴 간편결제·VAN 연동 API 키·웹훅 서명·IP 화이트리스트 재점검
- [ ] 상호명·대표자명·MID를 앞세운 **정산계좌 변경 사칭** 피싱 차단 공지

## 5. 공통 교훈

1. **핵심 DB는 지켰지만 주변 접점이 뚫렸다.** 외부 위탁·첨부파일·레거시 연동이 반복 지점입니다.
2. **정상 토큰으로 반복 호출하면 인증은 통과한다.** 인가(권한)와 사용량 이상 탐지가 필요합니다.
3. **사고 공지의 규모는 줄어들 수 없다.** 한전은 1개월 만에 3.5만 명이 추가 확인됐습니다. 초기 발표를 최종 규모로 가정하지 마세요.
