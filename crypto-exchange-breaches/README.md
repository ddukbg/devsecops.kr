# 국내 가상자산 거래소 연쇄 침해 — 빗썸 15일 침입과 주변 접점

[한국어](README.md) | [English](README_en.md)

빗썸 사내 그룹웨어(다우오피스) 해킹이 당초 공지된 **1시간이 아니라 10월 12일부터 27일까지 보름(15일)** 간 이어졌다는 사실이 11월 25일 추가 확인됐습니다. 10~11월 국내 가상자산 거래소 5곳이 연쇄 침해를 겪었고, 뚫린 곳은 콜드월렛이 아니라 **그룹웨어·외주 상담사·핫월렛** 같은 주변 접점이었습니다.

## 빗썸

- 침입 기간: **2026-10-12 ~ 10-27** (15일)
- 유출 범위: 기존 7,159명 → 고객·협력업체·전현직 임직원으로 확대 (추가 인원 비공개)
- 유출 항목: 주민번호·여권·운전면허·신분증 사본·계좌번호·거래내역·지갑주소 등 **19개**

## 거래소 5곳

| 거래소 | 내용 |
| --- | --- |
| 빗썸 | 그룹웨어(다우오피스) 15일 침입, 19개 항목 |
| 코인원 | 외주 상담사 '메타엠' 해킹 — 비밀번호·주민번호·지갑주소 등 11개 항목 가능성 |
| 고팍스 | 9월 침해 9명 → 2,009명 확대, 11/6 협박 메일로 입출금 15일 넘게 중단 |
| 프라뱅 | 10/24 핫월렛에서 약 1억 원 상당 탈취 |
| 플라이빗 | 11/1 다우기술 그룹웨어 경로로 고객 40명 노출 |

## 공통 패턴

- **그룹웨어·협업 도구**가 1차 침입점 (빗썸, 플라이빗 모두 다우오피스/다우기술 경로)
- **외주 상담사·수탁사**의 계정이 고객 데이터 접근 권한을 그대로 가짐
- **핫월렛**은 여전히 온라인에 연결된 자금 경로
- 침입 기간이 공지보다 길다 — 초기 발표를 최종 범위로 보면 안 됨

## 실무 체크리스트

### 거래소·핀테크

- [ ] 그룹웨어 MFA 강제, 비정상 위치·시간 로그인 차단
- [ ] 첨부파일·문서 반출 탐지 (대량 다운로드, 외부 메일 전송) 경보
- [ ] 외주·수탁사 계정 분리 발급, 접근 범위·기간 제한, 사용량 모니터링
- [ ] 핫월렛 잔액 상한·다중 서명·출금 지연(Time lock)
- [ ] 침입 공지 전 **로그 보존 기간**과 포렌식 절차 확인

### 사용자

- [ ] 거래소 사칭 보이스피싱·**지갑주소 변경 유도** 차단 (공식 앱·공지로만 확인)
- [ ] 출금 주소록 재확인, 신규 주소 등록 후 대기 시간 설정
- [ ] 유출 항목(신분증 사본·계좌) 악용 대비, 비밀번호·인증수단 재설정

### 사내 일반 기업

- [ ] 그룹웨어 계정 탈취 시 사내 문서·메일·주소록이 한 번에 노출되는 구조 점검
- [ ] 외주 수탁사 망분리·API 키 분리
